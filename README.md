# Fall Festival Roster — Local Storage Lab

## Project Information
- Course: CS 4360 — Mobile App Development
- Student: Brian Smith
- Level: Undergraduate
- GitHub Repository: https://github.com/Bsmith01cs/local-storage-lab

**Flutter version:** Flutter 3.47.5 (channel stable), Dart 3.13.4
**Device/platform:** Android emulator `sdk gphone16k arm64` (Pixel 7 AVD), Android 17 (API 37), device ID `emulator-5554`
**Database:** SQLite via sqflite; `MyDatabase.db`, `my_table(_id INTEGER PRIMARY KEY, name TEXT NOT NULL, age INTEGER NOT NULL)`.
**Implementation:** One initialized DatabaseHelper instance; async CRUD; ID-targeted update/delete; form validation; query-based refresh.

## Setup

```sh
cd local_storage_lab
flutter pub get
flutter emulators --launch <emulator-id>   # or start the Pixel 7 in Android Studio Device Manager
flutter devices
flutter run -d emulator-5554
```

Dependencies added to `pubspec.yaml`: `sqflite: ^2.4.1`, `path_provider: ^2.1.5`, `path: ^1.9.0`.

## Reflections (undergraduate prompts 1–3 only; 2–4 sentences each)

### 1. Disappearing-data mystery
**Prediction before T4:** TODO — write the prediction you made before stopping the app.
**Observed after T4:** Before stopping, the roster showed ID 1 River 21 and ID 2 River 35 with count 2 (`evidence/T4_before.png`). After stopping the app (TODO: confirm method) and reopening the same installed app without clearing storage, it showed the same IDs, names, ages and count (`evidence/T4_after.png`).
**Data flow:** `main()` awaits `DatabaseHelper.init()`, which opens `MyDatabase.db` in the app documents directory. `RosterScreen.initState()` calls `_refresh()`, which awaits `queryAllRows()` and `queryRowCount()` and then calls `setState` to rebuild the list. The guests are not kept in a Dart list between launches, so their return after a restart came from SQLite.
**Disproof:** If the roster had come back empty, with different IDs, or with B at age 34 instead of 35, the data would not have been restored from the database.

### 2. Two Rivers, one wrong edit
Both guests are named River, so a name cannot tell them apart; SQLite gave them separate `_id` values 1 and 2. Edit stores the selected row's `_id`, and Cancel clears it without writing anything. Saving calls `update()` with `WHERE _id = 2`, which produced "Updated ID 2 (1 row affected)." and changed only B to 35 while A stayed River 21 and the count stayed 2.

## Troubleshooting / changes
- `flutter run -d macos` failed because Xcode is not installed, so the app was tested on the Android emulator instead.
- `flutter run -d emulator-5554` reported no device when the emulator was not running; starting the Pixel 7 emulator first fixed it.
- The first Android build installed Android SDK Platform 35 and CMake 3.22.1 automatically and took about 5 minutes.
- `flutter analyze` first reported two `curly_braces_in_flow_control_structures` lints in `lib/main.dart` and an error in `test/widget_test.dart` (the default counter test still referenced `MyApp`). Braces were added and the test was replaced with an empty-roster smoke test.
